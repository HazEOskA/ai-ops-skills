# Tool Map

## Core tools

- Claude Code: repo execution, coding, refactors
- ChatGPT Project: strategy, architecture, analysis
- GitHub: source of truth
- VoltAgent: TypeScript agent runtime
- MCP: external tool connectors
- Termux / DeX / VPS: mobile-first dev environment
- Railway / VPS: backend deployment
- Vercel / Netlify: frontend deployment
- Redis / Postgres: memory and state

## Tool rule

Every tool must define:

- name
- purpose
- input schema
- output schema
- permissions
- risk level
- failure modes
