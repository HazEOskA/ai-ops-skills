# AI Ops Skills Architecture

## Purpose

This repo is the source of truth for reusable AI operating procedures.

## Layers

1. Human Operator
2. ChatGPT / Claude strategic interface
3. Skills as operating procedures
4. VoltAgent runtime
5. MCP connectors
6. Tool execution layer
7. Memory and state
8. Observability and audit

## Principle

Skills do not store secrets. Skills define behavior.
Tools execute behavior.
Repos preserve history.
